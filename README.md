
# IIT Delhi Economics – Industry Requirements and Existing Training

## 1. Project Overview

This project examines selected Job Notification Forms (JNFs) from IIT Delhi's 2023–24 placement records to demonstrate the connection between industry requirements and the capabilities developed through existing Economics training.

The objective is to identify the analytical, quantitative, computational, financial and research skills sought by employers and map them to relevant areas of the M.Sc. Economics programme at IIT Delhi.

The final report presents eight illustrative company-role examples across data science, quantitative analytics, banking, investment research, consulting and strategy.

## 5. Sampling and Text Extraction Methodology

The Python script performs the following operations:

1. Iterates through the existing classification folders.
2. Randomly selects up to four PDF files from each category.
3. Uses a fixed random seed (`42`) to ensure reproducibility.
4. Attempts text extraction using PDFPlumber.
5. Automatically applies Tesseract OCR when a page contains little or no extractable text.
6. Identifies relevant skills using a predefined keyword dictionary.
7. Extracts supporting text from the JNFs for the identified skills.
8. Maps the identified skill categories to relevant areas of Economics coursework.
9. Exports the results into a CSV file.

The sample size can be changed using:

```python
SAMPLE_SIZE = 4
```

A different random sample can be generated by changing:

```python
random.seed(42)
```

## 8. Important Methodological Considerations

- The sample is illustrative and should not be interpreted as statistically representative of all IIT Delhi campus recruitment.
- Skill identification is based on keyword matching and should be checked against the original JNF.
- A detected keyword may appear in a company overview or descriptive section rather than as a mandatory job requirement.
- OCR may introduce recognition errors, so extracted text should be checked against the original PDF when necessary.
- A blank skills field does not necessarily mean that a role has no relevant requirements.
- Coursework mappings indicate areas of relevance and do not imply that every application is taught in a specific course or that every student has mastered every skill.

## 9. Final Objective

The project aims to provide concrete examples of how capabilities developed through existing Economics training align with skills sought by organisations recruiting at IIT Delhi.

It highlights the applicability of Economics beyond conventional economist positions, particularly in quantitative analytics, data science, financial analysis, investment research, consulting and strategy.
